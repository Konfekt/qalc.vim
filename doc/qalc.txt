==============================================================================
OVERVIEW                                                       *qalc-overview*

This plugin calculates expressions directly within your text by the external
program "qalc" of the Qalculate! project.

Select or move over an expression such as "1 + 2" and press a mapping:
    - "q+" appends the result (adding " = result" after the expression),
    - "q=" replaces the expression by its result.

When you have an expression like: >
     1+2
and type "q++", the line becomes: >
     1+2 = 3
<
In replacement mode (using "q=="), the expression is replaced by just the
result, "3", padded with spaces to the width of the expression.

The plugin respects 'commentstring'. If the expression is within a commented
line (for example, "// 1+2"), the comment markers are removed while the
expression is calculated, and put back afterwards. Any previously calculated
result (the text after an "=" that is not part of a comparison such as "==",
"!=", "<=" or ">=") is removed and replaced by a fresh calculation.

By default, results are shown with at most 2 decimal places; change this by
|g:qalc_parameters|. Lines can hold multiple expressions separated by "|",
";" or tabs, as set by |g:qalc_splits|, so that, say, each cell of a table is
calculated.

==============================================================================
REQUIREMENTS                                               *qalc-requirements*

- Vim 8.2.0924 or later, or Neovim 0.5 or later.
- The "qalc" command must be installed and in your $PATH; otherwise the plugin
  does not load.

==============================================================================
USAGE                                                             *qalc-usage*

The default key mappings are:

   Normal Mode:
     q={motion}   Replace the expression(s) by their calculated result.
     q+{motion}   Append " = result" to each expression.
     q==          Like q= on the current line ([count] lines).
     q++          Like q+ on the current line ([count] lines).

   Visual Mode:
     {Visual}q=   Same as above, but for the selected text.
     {Visual}q+   Same as above, but for the selected text.

A default mapping is not defined if a mapping starting with "q=" or "q+"
already exists.
                                                          *g:qalc_no_mappings*
To disable the default mappings, add >
    let g:qalc_no_mappings = 1
to your vimrc and map your own keys to:

                                        *<Plug>(QalcReplace)* *<Plug>(QalcAppend)*
    <Plug>(QalcReplace)  - for replacement mode,
    <Plug>(QalcAppend)   - for append mode.

For example: >
    nmap <Leader>+ <Plug>(QalcAppend)
    xmap <Leader>+ <Plug>(QalcAppend)
    nmap <Leader>= <Plug>(QalcReplace)
    xmap <Leader>= <Plug>(QalcReplace)
<
Use |:nmap| and |:xmap|, as <Plug> mappings do not work with |:noremap|.

==============================================================================
CUSTOMIZATION                                             *qalc-customization*

                                                           *g:qalc_parameters*
Arguments passed to qalc, for example to change the decimal precision: >
      let g:qalc_parameters = '--set "min decimals 0" --set "max decimals 2"'
<
                                                               *g:qalc_splits*
Patterns that split a line into multiple expressions: >
      let g:qalc_splits = ['|', ';', "\t"]
<
Each entry is a very nomagic (|/\V|) regular expression in which only the
backslash \ needs escaping. The first entry that matches a line splits it,
and the matched text is kept between the results.
